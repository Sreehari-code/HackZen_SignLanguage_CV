# Troubleshooting

- **Python version:** use 64-bit Python 3.13 (tested here) or 3.11. Confirm with `python --version` or `py -0p`. The launcher deliberately does not install Python.
- **`No matching distribution found for mediapipe==0.10.21`:** requirements now pin MediaPipe 1.1.0, available for the current Python 3.13 package index. Delete the old `.venv`, recreate it using the Python you intend to run, then install the updated requirements.
- **`No module named cv2`:** dependency installation did not finish, or the app was started using a different interpreter than the one used by pip. Activate `.venv`, run `python -m pip install -r requirements.txt`, then check `python -c "import cv2, mediapipe; print(cv2.__version__, mediapipe.__version__)"` before launching. MediaPipe installs `opencv-contrib-python`, which provides `cv2`; do not install a separate OpenCV wheel alongside it.
- **PowerShell blocks activation:** run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that PowerShell window only, then activate `.\.venv\Scripts\Activate.ps1`. This change ends when the window closes.
- **No camera / camera busy:** quit video-call or camera applications, connect the webcam, allow desktop apps under Windows camera privacy settings, and set `camera_index` in `config.json` (try 1 for a second camera).
- **Model download fails:** first launch needs internet access to the configured HTTPS model URL. Check network/proxy access, then rerun. The file is stored under `models/gesture_recognizer.task` and is reused locally.
- **No hand detected:** improve front lighting, place one hand fully in view, and avoid a cluttered background.
- **No phrases added:** hold a gesture steadily, check the mode/confidence display, tune `confidence_thresholds.builtin` or `.custom`, or lower `stability_frames` in `config.json`. HELLO requires holding the open palm still briefly to distinguish it from the GOODBYE wave.
- **No phrase audio:** accepted phrases are spoken automatically unless `speak_each_phrase` is false. Check the window's speech status, confirm `pyttsx3` installed in the same `.venv` used to launch the app, and check Windows audio output/voice availability. Press S to retry the full sentence. Recognition remains usable if speech is unavailable.
- **Window/backend issues:** update the webcam driver and avoid other OpenCV builds in the same environment; use the supplied pinned requirements in a clean virtual environment.
- **Configuration error:** validate JSON syntax and parameter ranges. Gesture mapping keys must match MediaPipe category spelling exactly.
- **Custom static classes unavailable:** this is expected before training. Collect examples for at least two configured phrase labels and the `__OTHER__` rejection label (20 minimum each; 100+ recommended), run `python train_gesture_model.py`, and review class metrics before relying on the model.
- **Custom model load error:** confirm `models/custom_gesture_model.joblib` was generated by this project's trainer and its trained labels still exist/enabled in `config.json`. The app falls back to built-in and motion recognition if the model is invalid.
- **Static poses confused:** inspect the confusion matrix, collect more balanced varied samples, and choose hand shapes/orientations that are easier to distinguish. Captures from the same pose/session can make validation look better than real use.
- **GOODBYE wave not triggered:** start with a clearly recognized Open_Palm, move side-to-side by a visible distance, make at least the configured reversals within the motion window, then hold still for the finish pause. Tune `motion` settings conservatively for your camera. Only this side-to-side motion is implemented; NEXT/GO BACK depth trajectories are not.
